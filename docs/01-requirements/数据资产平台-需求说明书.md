## 1. 背景与目标

### 1.1 背景

企业分析计算首期落在 **Apache Doris**。缺少统一目录时会出现：找不到表、看不懂字段、改表不知影响面、业务口径无法沉淀，SQL 补全与 AI 问数也会失准。DataWorks 以数据地图作为企业数据目录。本平台 P0 对标该能力，先把 Doris 的库表字段采全、可搜、可预览，并作为 SQL 开发与 AI 问数的元数据底座。

### 1.2 目标

| 编号 | 目标 | 成功标准（P0） |
|------|------|----------------|
| G1 | 统一数据视图 | P0 完成至少 1 套 Doris 集群的库/表/字段/分区进入同一目录 |
| G2 | 像搜引擎一样找数 | 支持表名、字段名、中文注释关键词检索，P95 < 1s（百万级表内） |
| G3 | 理解数据 | 表详情含基本信息、字段、分区、产出信息、使用说明 |
| G4 | 追溯与影响分析 | 表级血缘可视化；字段级血缘至少覆盖 SQL 作业解析场景 |
| G5 | 业务组织资产 | 支持类目树与数据专辑（业务视角合集） |

### 1.3 非目标（本期不做）

- 数据集成作业开发、周期调度编排（见 SQL 开发 P1；集成 P1）
- 质量规则配置与监控告警闭环（P1，资产页仅预留入口）
- 数据服务 API 一键生成（P2，详情页可预留「生成 API」）
- 完整安全中心 / 脱敏策略中心（P2，本期仅权限申请工单雏形）
- 非 Doris 引擎采集（MySQL 等为 P1）
- AI 模型/算法任务资产与模型血缘（P2+，模型预留类型枚举）
- SQL 编辑器与 AI 对话本身不在本文，见配套需求说明书

## 4. 功能需求

### 4.1 数据总览

**对标**：数据地图首页 / 数据总览。

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-OV-01 | 展示资产规模：数据源数、库数、表数、字段数、近 7 日新增/变更表 | P0 |
| ASSET-OV-02 | 按引擎/数据源类型分布、按工作空间分布、按 Owner 分布 | P0 |
| ASSET-OV-03 | 采集健康度：成功/失败采集任务、最近同步时间、积压 | P0 |
| ASSET-OV-04 | 快捷入口：最近浏览、我的收藏、我管理的专辑 | P0 |
| ASSET-OV-05 | 存储量、生命周期即将到期表 Top N（有采集到存储/TTL 时展示） | P1 |

### 4.2 工作空间、数据源与连接

数据资产不单独造「计算引擎」，但必须能绑定已登记的数据源。

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-DS-01 | 工作空间：名称、环境（dev/prod）、成员与角色 | P0 |
| ASSET-DS-02 | 数据源登记：类型、连接信息（密钥脱敏存储）、探测连通性 | P0 |
| ASSET-DS-03 | P0 引擎类型：**Apache Doris**（FE 地址、HTTP/JDBC 端口、Catalog/Database 范围、用户只读账号） | P0 |
| ASSET-DS-04 | 扩展类型：MySQL、Hive / Iceberg、StarRocks、PostgreSQL、ClickHouse 等 | P1 |
| ASSET-DS-05 | 数据源与工作空间绑定；同一数据源可被多工作空间只读引用（可配置） | P1 |

### 4.3 元数据采集

**对标**：DataWorks 采集器（Crawler）。从分散数据源抽取库、表、字段、分区、存储量、更新时间，汇入统一元数据仓库。

#### 4.3.1 采集器模型

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-COL-01 | 采集器包含：名称、数据源、采集范围（库/schema 白名单黑名单）、调度（手动/周期）、并发与超时 | P0 |
| ASSET-COL-02 | 内置采集器：绑定 Doris 数据源后可自动/周期同步（information_schema + SHOW 语句） | P0 |
| ASSET-COL-03 | 自定义采集器：用户创建，解析源端物理结构，同步列属性、主键、分区、索引（有则采集） | P0 |
| ASSET-COL-04 | 采集内容：技术元数据（库/表/视图/字段/分区）、表大小、记录数（可采样或引擎统计）、生命周期 | P0 |
| ASSET-COL-05 | 可选采集：样例数据（受权限与脱敏约束）、注释、Owner（从引擎或平台映射） | P0 |
| ASSET-COL-06 | 结构变更检测：新增/删除/类型变更字段写入变更日志，检索侧可提示「近期变更」 | P0 |
| ASSET-COL-07 | 任务运行：运行历史、日志、失败原因、重跑、暂停 | P0 |
| ASSET-COL-08 | Doris 增量：按 `information_schema.tables` 的 `TABLE_VERSION` / `UPDATE_TIME`（以集群实际字段为准）增量，全量兜底 | P1 |
| ASSET-COL-10 | Doris 采集细节：Internal Catalog 及已映射 External Catalog（可选）；表模型（Duplicate/Unique/Aggregate）、分桶键、分区、副本、行数、数据量、COMMENT | P0 |
| ASSET-COL-09 | 插件化：采集器以 SPI/插件目录扩展，不改核心即可加引擎 | P1 |

#### 4.3.2 采集对象类型（统一资产模型）

P0 必须落地的实体：`Workspace`、`Datasource`、`Database/Schema`、`Table`、`Column`、`Partition`。

预留实体（模型有类型，UI 可灰显）：`View`、`Index`、`API`、`Dataset`、`Code`、`Model`。

### 4.4 元数据检索与发现

**对标**：全局关键字搜索 + 高级筛选。

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-SR-01 | 全局搜索：表名、字段名、中文注释、业务术语；支持模糊与分词 | P0 |
| ASSET-SR-02 | 搜索范围：只搜表 / 只搜列 / 表+列 | P0 |
| ASSET-SR-03 | 结果卡片：表名、中文名、数据源类型、库、工作空间、Owner、更新时间、热度（浏览/读取次数，有则显示） | P0 |
| ASSET-SR-04 | 组合筛选：类型、数据源/引擎、工作空间、环境、Owner、标签、类目、数据库 | P0 |
| ASSET-SR-05 | 结果操作：打开详情、查看血缘、申请权限、收藏 | P0 |
| ASSET-SR-06 | 无结果引导：提示采集是否完成、同义词/类目浏览 | P1 |
| ASSET-SR-07 | 代码检索：按作业/脚本内容搜表引用（依赖开发模块，P1） | P1 |
| ASSET-SR-08 | 检索权限：无库表权限者可见元数据摘要，不可预览数据；可配置「元数据是否全员可见」 | P0 |

### 4.5 资产详情

**对标**：表详情（基本信息、字段、产出、血缘、质量、预览）。

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-DT-01 | 基本信息：全限定名、引擎类型、工作空间、环境、Owner、创建/变更时间、存储量、生命周期、浏览/读取次数 | P0 |
| ASSET-DT-02 | 字段列表：名称、类型、是否分区、是否主键、可空、注释、安全等级、示例值（可选） | P0 |
| ASSET-DT-03 | 分区信息：分区键、分区数量、最近分区、分区预览列表（分页） | P0 |
| ASSET-DT-04 | 产出信息：关联调度任务、最近成功产出时间（无调度模块时允许空态 + 手动登记） | P0 |
| ASSET-DT-05 | 使用说明：富文本/Markdown，Owner 可编辑，支持版本记录 | P0 |
| ASSET-DT-06 | 数据预览：限行、限列、权限校验；敏感列默认脱敏；无权限展示申请入口 | P0 |
| ASSET-DT-07 | 快捷动作：收藏、申请权限、加入专辑、复制 DDL、跳转血缘、**在 SQL 开发中打开**、**AI 问数引用此表** | P0 |
| ASSET-DT-08 | 质量摘要：规则通过率入口（无质量模块时占位） | P1 |
| ASSET-DT-09 | 生成 API / 去分析（占位，跳转后续模块） | P2 |

### 4.6 数据血缘

**对标**：表血缘、字段血缘、影响分析；血缘来自调度作业与数据流转解析，不含临时查询（P0 与 DataWorks 一致）。

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| ASSET-LN-01 | 表级血缘图：上下游展开、层级控制、全屏、节点属性面板（类型、源、存储、生命周期） | P0 |
| ASSET-LN-02 | 字段级血缘：由 SQL 解析器抽取列级读写关系；无法解析时降级为表级并标记「列级未解析」 | P0 |
| ASSET-LN-03 | 影响分析：给定表/字段列出全部下游（表、任务、API 预留）；支持导出与邮件/站内通知 Owner | P0 |
| ASSET-LN-04 | 血缘边属性：作业 ID、解析时间、解析置信度、转换类型（insert/select/sync） | P0 |
| ASSET-LN-05 | 血缘来源：采集器上报、SQL 解析入库、同步任务登记；手动补边（管理员） | P1 |
| ASSET-LN-06 | 更新时效：离线 T+1 可接受；P1 支持作业完成后增量更新 | P0/P1 |
| ASSET-LN-07 | 跨引擎血缘：同步任务两侧表连边（依赖集成模块后打通） | P1 |

## 5. 领域模型（逻辑）

```text
Workspace 1──n Datasource 1──n CollectorJob 1──n CollectorRun
Datasource 1──n Database 1──n Table 1──n Column
Table 1──n Partition

Table n──n Tag
```

## 9. 验收要点

1. 配置 Doris 采集器后，指定 Catalog/Database 下的库表字段可在搜索中出现。  
2. 中文注释关键词可命中表。  
3. 打开表详情可见字段、分区（若有）、使用说明可编辑。  
4. 有 SQL 作业血缘样本时，可展开上下游并查看至少一张表的字段血缘。  
5. 影响分析可导出下游列表。  
6. 可创建专辑并把表加入，首页能看到关注专辑。  
7. 无预览权限用户看到申请入口，审批通过后可预览（脱敏）。  
8. 采集失败有日志并可重跑，不阻塞已有元数据查询。
