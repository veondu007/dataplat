# SQL 开发平台需求说明书

- 文档编号：DP-REQ-SQL-001
- 版本：v0.2
- 日期：2026-09-14
- 状态：草案
- 所属产品：DataPlat
- 参考产品：阿里云 DataWorks **Data Studio / 临时查询**
- 执行引擎：**Apache Doris**（MySQL 协议）
- 执行身份：**Doris 个人账号**（与平台登录用户 1:1 映射）

---

## 1. 背景与目标

### 1.1 背景

数仓日常工作是写 SQL、跑 SQL、改 SQL。DataWorks 将「临时查询」与「周期作业开发」分开：前者服务即席分析，后者进调度。本平台 P0 先做稳 **Doris 上的 SQL 工作台**，P1 再上工作流与运维中心，避免首期同时做 IDE 与调度内核。

### 1.2 目标

| 编号 | 目标 | 成功标准（P0） |
|------|------|----------------|
| G1 | 可连接 Doris 执行 | 工作空间绑定 Doris 后，授权用户可提交查询并看到结果 |
| G2 | 像 IDE 一样写 SQL | 语法高亮、补全（库/表/字段来自数据资产）、括号匹配、只读执行 |
| G3 | 可沉淀脚本 | 个人/空间目录保存 `.sql`，历史可回看 |
| G4 | 安全可控 | 超时、行数/字节上限、禁止默认跑无 LIMIT 的全表扫描（可配置拦截） |
| G5 | 为血缘与问数供数 | 保存并发布的作业 SQL 可被血缘解析；临时查询默认不进血缘（与 DataWorks 一致） |

### 1.3 非目标（P0 不做）

- 多节点 DAG、依赖、基线、补数据（P1 运维调度）
- Spark/Hive/Flink 多引擎作业（P1+）
- 数据集成节点、质量节点混排（P1）
- 本地 Git 双向同步（P1，可先做平台内版本）

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 分析师 | 打开临时查询，从资产页「在 SQL 中打开」带出表名，LIMIT 预览后导出 CSV |
| 数仓开发 | 在空间目录维护 `dwd_order.sql`，EXPLAIN 调优，提交给 Owner Review（P1） |
| AI 问数 | 用户确认 SQL 后，复用同一 SQL Gateway 执行与展示结果 |
| 管理员 | 配置查询队列、超时、最大返回行数；采集账号与个人查询账号分离 |

## 4. 功能需求

### 4.1 计算源与执行上下文

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-CTX-01 | 查询绑定：工作空间 + Doris 数据源 + 默认 Catalog/Database | P0 |
| SQL-CTX-02 | 执行身份：**平台用户 1:1 绑定 Doris 个人账号**。Gateway 用该账号连接 FE，权限以 Doris GRANT 为准；未绑定账号不可执行 | P0 |
| SQL-CTX-05 | 用户在平台维护本人 Doris 连接凭证（密码或后续 LDAP）；凭证加密存储，仅 Gateway 解密；禁止共享他人账号 | P0 |
| SQL-CTX-03 | 环境：dev/prod 数据源隔离，禁止 prod 临时查询默认写（P0 临时查询仅允许 SELECT/SHOW/EXPLAIN/DESC） | P0 |
| SQL-CTX-04 | 会话变量：可设置 query timeout、并行度等白名单 session variable | P1 |

### 4.2 SQL 编辑器

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-ED-01 | Monaco/同类编辑器：Doris SQL 高亮、多 Tab、只读只写状态 | P0 |
| SQL-ED-02 | 补全：关键字、函数、Catalog、Database、Table、Column（数据来自资产服务，热更新） | P0 |
| SQL-ED-03 | 悬停：字段类型、中文 COMMENT、安全等级 | P0 |
| SQL-ED-04 | 跳转：Ctrl/Cmd+点击表名打开资产详情 | P0 |
| SQL-ED-05 | 格式化、注释、查找替换 | P0 |
| SQL-ED-06 | 语法诊断：提交前轻量校验（括号、未闭合字符串）；完整 Parser P1 | P0 |
| SQL-ED-07 | 从数据资产「复制 DDL / 生成 SELECT」插入编辑器 | P0 |

### 4.3 执行与结果

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-EX-01 | 运行选区或全脚本；多语句按 `;` 拆分，默认只执行当前语句 | P0 |
| SQL-EX-02 | 停止正在运行的查询（KILL QUERY） | P0 |
| SQL-EX-03 | EXPLAIN / EXPLAIN VERBOSE 一键 | P0 |
| SQL-EX-04 | 结果网格：分页或前端窗口（默认上限 1 万行 / 20MB，可配） | P0 |
| SQL-EX-05 | 导出 CSV/Excel（二次权限校验；敏感列按资产等级脱敏） | P0 |
| SQL-EX-06 | 简易图表：数值列柱状/折线（问数模块可复用） | P1 |
| SQL-EX-07 | 展示 QueryId、耗时、扫描行数/字节（Doris profile 摘要） | P0 |
| SQL-EX-08 | 失败信息完整展示（语法错误、权限、超时、FE 提示） | P0 |
| SQL-EX-09 | 无 LIMIT 的大表 SELECT 拦截或强制改写（策略可配：拦截 / 警告 / 自动 LIMIT） | P0 |

### 4.4 临时查询与脚本仓库

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-AD-01 | 临时查询不默认入库血缘；可勾选「保存为脚本」 | P0 |
| SQL-AD-02 | 运行历史：SQL 摘要、状态、耗时、操作人、可再打开 | P0 |
| SQL-REPO-01 | 空间目录 + 个人目录；权限按空间角色 | P0 |
| SQL-REPO-02 | 创建/保存/重命名/移动/删除；删除进回收站（P1 可做真回收） | P0 |
| SQL-REPO-03 | 每次保存生成版本，支持对比与回滚最近 N 版 | P1 |
| SQL-REPO-04 | 分享只读链接给空间成员 | P1 |

### 4.5 对象浏览器

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-OB-01 | 左侧树：Doris Catalog → Database → Table/View → Column | P0 |
| SQL-OB-02 | 数据来自资产采集，支持刷新单库元数据 | P0 |
| SQL-OB-03 | 拖拽表名到编辑器生成 `catalog.db.tbl` 或 SELECT 模板 | P0 |
| SQL-OB-04 | 无权限对象灰显并提供申请权限（复用资产 ACL） | P0 |

### 4.6 SQL Gateway（平台级，AI 问数复用）

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-GW-01 | 统一提交入口：解析当前用户 Doris 凭证 → 方言检查 → 以该身份连接 FE → 拉结果 → 审计（含 Doris user） | P0 |
| SQL-GW-02 | 写操作白名单：P0 临时查询与问数关闭 INSERT/UPDATE/DELETE/DROP/ALTER | P0 |
| SQL-GW-03 | 并发与队列：按用户/空间限流，防止打满 Doris | P0 |
| SQL-GW-04 | 审计：谁、何时、哪条 SQL、QueryId、行数、是否下载 | P0 |
| SQL-GW-05 | 结果集短时缓存（相同 SQL+权限，TTL 可配），减轻重复问数 | P1 |

### 4.7 与血缘、调度（P1）

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SQL-JOB-01 | 脚本发布为周期节点：cron、失败重试、实例运维 | P1 |
| SQL-JOB-02 | 发布成功后解析 INSERT/CREATE TABLE AS 写入资产血缘 | P1 |
| SQL-JOB-03 | 开发/生产发布流程与审批 | P1 |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 延迟 | 提交到 Doris 开始执行 < 500ms（不含排队与 SQL 本身） |
| 稳定 | Gateway 与编辑器断开后任务可后台跑完，刷新可取结果（P0 至少结果保留 30 分钟） |
| 安全 | SQL 文本落审计；个人 Doris 密码加密存储且不进浏览器、不进问数 Prompt；结果下载记日志 |
| 方言 | 按 Doris 版本配置（建议 2.1+），函数补全与版本对齐 |
| 复用 | AI 问数不得另接一套 JDBC，必须走 SQL Gateway |

## 7. 验收要点

1. 当前用户绑定个人 Doris 账号后，可对 **该账号有权限** 的表执行 `SELECT ... LIMIT 100` 并展示结果。  
2. 输入表名可补全到字段，且 COMMENT 可悬停。  
3. `DROP TABLE` 在临时查询被拒绝。  
4. 超行数被截断并提示。  
5. 运行历史可重新打开 SQL。  
6. 资产详情「在 SQL 开发中打开」带出正确限定名。  
7. 同一条查询的 QueryId 可在审计中按平台用户 + Doris 用户查到。  
8. 用户 A 无法用自己的会话跑出仅授予用户 B 的表（引擎侧拒绝或对象树不可见）。
