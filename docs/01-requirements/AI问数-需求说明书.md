# AI 问数需求说明书

- 文档编号：DP-REQ-AIQA-001
- 版本：v0.2
- 日期：2026-09-14
- 状态：草案
- 所属产品：DataPlat
- 参考能力：DataWorks Copilot / 智能问数、业界 ChatBI（资产检索 + NL2SQL + 确认执行）
- 执行引擎：**Apache Doris**（必须经 SQL Gateway，**个人账号**执行）
- 大模型：**公有云 API**（OpenAI 兼容协议，平台托管密钥）

---

## 1. 背景与目标

### 1.1 背景

业务与分析师希望用中文提问直接出数，而不是先找表再写 SQL。没有资产目录和权限闸门的 NL2SQL 容易编造表名、扫全表、泄露敏感列。本模块建立在 **数据资产 + SQL Gateway** 之上：先检索可信表与口径，再生成 Doris SQL，**展示给用户确认后才执行**。

### 1.2 目标

| 编号 | 目标 | 成功标准（P0） |
|------|------|----------------|
| G1 | 中文问数 | 对已采集且用户有权限的 Doris 表，常用聚合/筛选问句可生成可执行 SQL |
| G2 | 可解释 | 每次回答展示：用了哪些表/字段、SQL 全文、置信度或注意事项 |
| G3 | 可控执行 | 默认只读；未确认不执行；写语句直接拒绝 |
| G4 | 可追责 | 对话、检索到的表、SQL、QueryId、结果行数全部审计 |
| G5 | 可纠错 | 用户可改 SQL 再跑，或点「答错了」反馈 |

### 1.3 非目标（P0 不做）

- 完整指标平台 / 语义层建模（P1，可先用表 COMMENT、专辑、同义词凑合）
- 自动写数仓作业、自动建表  
- 跨引擎联邦问数  
- 无人值守定时推送报表（P1）  
- 用模型直接「编造」未采集的表  

---

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 业务人员 | 「上周各渠道 GMV 是多少？」→ 看图表 → 下载 |
| 分析师 | 问数得到 SQL 后点「在 SQL 开发中打开」继续改 |
| 数仓 Owner | 配置问数范围（专辑/类目）、同义词、禁问字段 |
| 安全 | 敏感列默认不选中、结果脱敏、全链路审计 |

对话示例（P0 应能覆盖的句型）：

- 单表筛选 + 聚合：某表按日求和、TopN  
- 时间范围：昨天 / 上周 / 本月（需日期字段可识别）  
- 简单两表 Join：资产中已有 COMMENT 或人工配置的关联  
- 追问：在上一问结果上加过滤（会话记忆）

## 3. 总体能力地图

```text
AI 问数
├── 对话工作台
├── 问数范围（空间 / 专辑 / 指定表）
├── 检索（资产 RAG：表、字段、说明、同义词）
├── NL2SQL（Doris 方言）
├── SQL 确认 / 编辑 / 一键到 SQL 开发
├── 执行（SQL Gateway）
├── 结果：表 + 简易图表 + 自然语言解读
├── 反馈与样例沉淀
└── 管理：模型配置、提示词、禁问策略     ← 部分 P1
```

流水线（P0 强制顺序）：

```text
用户问题
  → 权限内资产检索（表/字段/文档）
  → 生成候选 SQL（仅 SELECT）
  → 静态检查（表存在、无写操作、LIMIT、敏感列）
  → 展示 SQL 与依据，用户确认
  → Gateway 执行
  → 表格/图表 + 简要解读
```

## 4. 功能需求

### 4.1 对话与范围

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-CH-01 | 多轮对话：新建/历史会话，展示问题、检索依据、SQL、结果 | P0 |
| AIQA-CH-02 | 问数范围：当前空间全部有权限表，或限定某个数据专辑/类目 | P0 |
| AIQA-CH-03 | 从资产详情「用 AI 问此表」进入时锁定该表（可再勾选扩展） | P0 |
| AIQA-CH-04 | 会话内可切换 Doris 默认 Database | P0 |
| AIQA-CH-05 | 推荐问题：根据专辑或热门查询生成 3～5 条 | P1 |

### 4.2 资产检索与语义

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-RG-01 | 用问题检索表名、中文名、字段 COMMENT、使用说明、标签 | P0 |
| AIQA-RG-02 | 只返回当前用户有权限的表；无权限表不得进入 Prompt | P0 |
| AIQA-RG-03 | 同义词表：业务词 → 表/字段（如 GMV → `pay_amt`） | P0 |
| AIQA-RG-04 | 时间字段启发式：`*_date`、`dt`、`create_time` + COMMENT | P0 |
| AIQA-RG-05 | 指标语义层（原子指标、维度、口径 SQL 片段） | P1 |
| AIQA-RG-06 | 人工配置常用 Join 关系（主外键或业务关联） | P1 |

### 4.3 NL2SQL 与护栏

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-NL-01 | 生成 Apache Doris SQL，限定问数范围内的 Catalog.DB.Table | P0 |
| AIQA-NL-02 | 仅允许 SELECT / WITH；拒绝 DDL/DML/LOAD | P0 |
| AIQA-NL-03 | 强制或建议 LIMIT；聚合问句可不 LIMIT 但需估算策略 | P0 |
| AIQA-NL-04 | 不确定时澄清：多表候选让用户勾选，而不是瞎 Join | P0 |
| AIQA-NL-05 | 输出：SQL、使用的表/字段列表、假设说明（如「按支付成功口径」） | P0 |
| AIQA-NL-06 | 静态校验：表字段必须存在于资产快照；不存在则失败并提示刷新采集 | P0 |
| AIQA-NL-07 | 敏感字段：默认不 SELECT 出 L3/L4 列，或结果脱敏（与资产等级对齐） | P0 |
| AIQA-NL-08 | 模型：**公有云 OpenAI 兼容 API**。空间配置 Base URL、模型名；密钥由平台加密托管，不落前端。Prompt 绑定 Doris 方言版本 | P0 |
| AIQA-NL-09 | 出域最小化：上传问题文本 + 检索命中的表结构/COMMENT/同义词；**禁止**上传个人 Doris 密码、未脱敏样例行、全量查询结果 | P0 |

### 4.4 确认、执行与展示

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-RN-01 | 默认「生成 SQL → 用户点运行」；管理员可对受信专辑开「自动运行」（P1） | P0 |
| AIQA-RN-02 | SQL 可编辑后再运行；「在 SQL 开发中打开」带入工作台 | P0 |
| AIQA-RN-03 | 执行走 SQL Gateway：**以当前用户 Doris 个人账号**连接；超时、行数、审计、KILL 与开发平台一致 | P0 |
| AIQA-RN-04 | 结果表；若存在 1 个时间维 + 1 个度量，自动折线；维度+度量柱状 | P0 |
| AIQA-RN-05 | 用自然语言概括结果（不得与表格矛盾；数字必须来自查询结果） | P0 |
| AIQA-RN-06 | 执行失败：把 Doris 错误喂回模型尝试一次修正，仍失败则展示错误 | P0 |

### 4.5 反馈与治理

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-FB-01 | 赞/踩、错误原因（表错、口径错、过滤错、SQL 语法） | P0 |
| AIQA-FB-02 | 把优质问答沉淀为 few-shot（需 Owner 审核后才进全局） | P1 |
| AIQA-FB-03 | 问数看板：成功率、平均延迟、踩的比例、热门失败问题 | P1 |

### 4.6 管理配置

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| AIQA-AD-01 | 空间开关：是否启用问数、公有云模型名、温度、最大生成 token | P0 |
| AIQA-AD-05 | 平台级公有云密钥与可选空间级密钥覆盖；调用失败（额度/超时）对用户展示可理解错误 | P0 |
| AIQA-AD-02 | 禁问：正则或字段级（证件号、手机等） | P0 |
| AIQA-AD-03 | Prompt 模板可编辑（系统提示词含 Doris 语法要点） | P1 |
| AIQA-AD-04 | Token / 调用量配额 | P1 |

## 5. 安全与合规（P0 强制）

1. Prompt 中不得放入无权限表结构。  
2. 不得把样例数据里的真实敏感值送进模型（样例需脱敏）。  
3. 所有 SQL 经 Gateway 语法树或正则+Parser 双重拦截写操作。  
4. 对话与结果访问权限与会话创建者绑定，空间管理员可审计。  
5. **公有云模型**：默认认定表结构与问题会出域。结果解读若需二次调用模型，只上传聚合后的有限行（默认 ≤ 50 行且已脱敏），可在空间关闭「结果解读」以免明细出域。  
6. 问数执行不得改用采集账号或空间代理账号，必须与 SQL 开发同一套个人身份。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 延迟 | 检索+生成 SQL P95 < 8s（不含 Doris 执行） |
| 质量 | 在约定金标集（20～50 条业务问句）上可执行率 ≥ 70% 作为 P0 发布门槛（可随注释完善提升） |
| 成本 | 记录每次 token；超配额降级为「仅检索表，不生成」 |
| 依赖 | 资产未采集完成时，问数入口提示先采集，禁止空目录乱生成 |

## 7. 页面清单（P0）

1. 问数对话页  
2. SQL 确认卡片（依据、编辑、运行、跳转开发）

## 8. 验收要点

1. 仅采集了 Doris `orders` 时，问「昨天订单量」能生成对该表的 SELECT，且用户确认后跑出数字。  
2. 问未授权表相关问题时，不生成对该表的 SQL。  
3. 「帮我把这张表删掉」被拒绝。  
4. 生成 SQL 中的表字段均能在资产中找到。  
5. 运行后可跳转 SQL 开发，脚本内容一致。  
6. 审计能按用户查出该次 QueryId（含 Doris 个人用户名）。  
7. 资产无表时，问数明确失败原因而不是编造表名。  
8. 未绑定个人 Doris 账号时，允许生成 SQL 草稿，但运行按钮不可用并引导去绑定。
