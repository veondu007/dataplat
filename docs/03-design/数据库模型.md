# 数据库模型（P0）

- 文档版本：v0.1（独立于产品版本 `VERSION`）
- 日期：2026-09-14
- 状态：草案
- 对应需求：[数据资产平台-需求说明书](../01-requirements/数据资产平台-需求说明书.md) §5 领域模型

## 1. 范围

P0 必须先落地的核心实体：**工作空间（Workspace）、数据源（Datasource）、表（Table）、字段（Column）**。
其余（Database / Partition / View / Index / 血缘 / 类目 / 专辑等）在采集器与对应模块迭代时补充，此处仅列预留。

## 2. 领域模型（逻辑）

见需求说明书 §5：

```text
Workspace 1──n Datasource 1──n Database 1──n Table 1──n Column
```

统一资产 URN：`urn:dataplat:doris:{workspace}:{catalog}.{db}.{table}`。

## 3. 物理表结构（与 `apps/api/app/models/` 逐字段对齐）

### 3.1 workspaces — 工作空间

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| id | VARCHAR(64) | PK | 空间 ID（如 `ws-default`） |
| name | VARCHAR(128) | NOT NULL | 空间名称 |
| env | VARCHAR(16) | NOT NULL, default `dev` | dev / prod |
| created_at | TIMESTAMPTZ | NOT NULL, default now() | 创建时间 |

### 3.2 datasources — 数据源

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| id | VARCHAR(64) | PK | 数据源 ID |
| workspace_id | VARCHAR(64) | FK → workspaces.id | 所属空间 |
| name | VARCHAR(128) | NOT NULL | 数据源名称 |
| engine | VARCHAR(32) | NOT NULL, default `doris` | 引擎类型 |
| created_at | TIMESTAMPTZ | NOT NULL, default now() | 创建时间 |

### 3.3 tables — 表

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| id | VARCHAR(64) | PK | 表 ID（建议 URN） |
| datasource_id | VARCHAR(64) | FK → datasources.id | 所属数据源 |
| database_name | VARCHAR(128) | NOT NULL | 库名 |
| name | VARCHAR(128) | NOT NULL | 表名 |
| comment | TEXT | NULL | 中文注释（来自 COMMENT） |
| updated_at | TIMESTAMPTZ | NOT NULL, default now(), on update | 最近变更 |

### 3.4 columns — 字段

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| id | VARCHAR(64) | PK | 字段 ID |
| table_id | VARCHAR(64) | FK → tables.id | 所属表 |
| name | VARCHAR(128) | NOT NULL | 字段名 |
| data_type | VARCHAR(64) | NOT NULL | 类型（如 BIGINT / VARCHAR） |
| position | INTEGER | NOT NULL, default 0 | 列序号 |
| is_partition | BOOLEAN | NOT NULL, default false | 是否分区键 |
| comment | TEXT | NULL | 字段注释 |

## 4. Alembic 迁移

- 配置：`apps/api/alembic.ini`（`script_location = alembic`，DB URL 由 `env.py` 从 `DATAPLAT_DATABASE_URL` 注入）。
- `apps/api/alembic/env.py` 顶部显式 `sys.path.insert` 加入 `apps/api`，保证 Windows 上任意 CWD 都能 `import app`。
- 初始迁移：`alembic/versions/20260914_0001_initial.py`（手写，非 autogenerate——autogenerate 需要活库）。

```bash
cd apps/api
docker compose -f ../deploy/docker-compose.yml up -d postgres
alembic upgrade head
alembic current
alembic check          # 校验模型与迁移是否漂移
```
