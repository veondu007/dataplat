# 工程架构与技术选型

- 版本：v0.1
- 日期：2026-09-14
- 状态：草案
- 对齐：P0 数据资产 + SQL 开发 + AI 问数

## 1. 仓库形态

单仓 Monorepo。产品文档、前端控制台、后端 API、采集器、部署与 CI 同仓，版本号以仓库根目录 `VERSION` 为准。

## 2. 技术选型

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | React 18 + TypeScript + Vite + Ant Design 5 + React Router | 企业中后台；SQL 编辑器用 Monaco |
| 后端 | Python 3.10 + FastAPI + SQLAlchemy + Alembic | 本机 JDK 为 8，不适合新开 Spring Boot 3；NL2SQL 与采集同语言更顺 |
| 元数据库 | PostgreSQL 15 | 工作空间、资产、脚本、审计、会话 |
| 缓存 | Redis 7 | 查询结果短缓存、限流、会话 |
| 搜索 | P0 PostgreSQL 全文检索；资产量大后迁 OpenSearch | 避免首期再引入一套集群 |
| 计算 | Apache Doris（个人账号 JDBC/MySQL 协议） | 查询、预览、问数执行 |
| LLM | 公有云 OpenAI 兼容 API | 密钥仅后端持有 |
| 包管理 | 前端 npm；后端 pip + `requirements.txt` | |
| 容器 | Docker Compose（本地 / 测试）；生产 K8s 为 P1 | |
| CI | GitHub Actions | lint + 单测 + 构建 |

若后续强制 Java 栈：升级 JDK 17+ 后新增 `apps/api-java`，FastAPI 可收缩为 NL2SQL 与采集侧车。

## 3. 运行时拓扑（P0）

```text
浏览器
  └── apps/web (Nginx / Vite preview)
        └── /api        → apps/api  FastAPI

apps/api
  ├── 工作空间 / 用户绑定（Doris 个人账号凭证，加密存储）
  ├── 数据资产（采集任务、检索、详情、专辑）
  ├── SQL Gateway（透传个人账号连 FE）
  ├── AI 问数（检索资产 → 调公有云 → 确认后走 Gateway）
  └── collectors/doris（进程内或独立 worker）

PostgreSQL    Redis    Doris FE    公有云 LLM
```

前端不直连 Doris，不持有 LLM Key。

## 4. 应用与模块

| 路径 | 职责 |
|------|------|
| `apps/web` | 控制台：资产 / SQL 工作台 / 问数 / 个人账号绑定 |
| `apps/api` | 模块化单体 API + 采集 worker 入口 |
| `collectors/doris` | Doris 元数据采集 |
| `deploy/` | Compose、环境变量模板 |
| `docs/` | 需求与设计 |

## 5. 前端信息架构

| 路由 | 页面 |
|------|------|
| `/` | 总览 |
| `/assets` | 检索与类目 |
| `/assets/tables/:urn` | 表详情、预览、血缘 |
| `/albums` | 数据专辑 |
| `/collectors` | 采集器 |
| `/sql` | SQL 工作台 |
| `/sql/history` | 运行历史 |
| `/aiqa` | 问数对话 |
| `/settings/account` | 绑定 Doris 个人账号 |
| `/settings/workspace` | 空间与数据源 |

UI：Ant Design 顶栏空间切换 + 侧栏模块。三产品共用登录态与空间上下文。

## 6. 后端分层

```text
HTTP / OpenAPI → routers (v1) → services → repositories → clients (Doris / LLM / Redis)
```

统一响应：`{ "code", "message", "data", "request_id" }`。鉴权 P0 使用 JWT。

## 7. 安全边界

- Doris 密码、LLM Key 只存在服务端。
- SQL Gateway 以个人 Doris 用户连接；采集用独立只读账号。
- 问数出域：问题 + 命中表结构；禁止密码与未脱敏明细。
